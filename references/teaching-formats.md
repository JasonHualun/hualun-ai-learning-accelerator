# 讲解形式选择（文字 / 图表 / 互动网页 / 解释视频）

> 本篇是「用什么形式讲」的唯一真源。教什么、按什么顺序教仍以 `teaching-steps.md` 的费曼四步为准；本篇只决定**同一段内容用哪种形式呈现**。
> 灵感：Karpathy 关于「LLM 输出形式：文字 → 图表 → 网页 → 解释视频，越往后越好懂」的分享；ASD-STE100 不采用（与正文蒸馏模式「定义照搬原文」冲突，且「大白话、一次一概念」已有）。

## 一、讲新概念时主动选形式（不再等卡住）

费曼第二步（类比 → 定义）和第三步（例子）开讲前，先看这个概念是什么类型：

| 概念类型 | 例子 | 默认形式 |
|---|---|---|
| 有先后顺序（流程、因果链、循环） | Agent 循环、RAG 检索流向、货币传导 | **流程图**：消息里直接给 Mermaid / 文字框图；飞书不渲染时改发 PNG |
| 讲几个东西之间的关系（结构、层级、对比） | 框架误区 vs 领域误区、三种存储的区别 | **关系图 / 对比表** |
| 有能调的数值（一个变，另一个跟着变） | 供需与价格、复利、上下文长度与成本 | **互动网页**：可拖滑块的自包含 HTML（用 `show-me`） |
| 纯概念、靠感受理解 | 机会成本、心流 | **文字类比**（照旧） |

- 一个概念只选一种主形式，配一句文字说明；不为了花哨堆形式。
- 图和网页里的文字同样遵守「零黑话、生活比喻、元素与概念一一对应」。
- 讲完照旧让学生用自己的话复述，问「哪句/哪一处最不确定」。

## 二、解释视频（按需，不默认）

用共享 Skill **`hualun-explainer-video`** 做 1–3 分钟动画讲解（火柴人简笔画 + 本地配音 + 字幕 + 公式逐项标注，默认王虹手写风）。

- **何时做**：
  1. 用户说「做个视频」「视频讲讲」「动画讲一下」；
  2. 章节收尾时，在问复习提醒的同一句里顺带问「要不要把这章最难的概念做成一个讲解视频，复习时看？」，用户同意才做。
- **内容来源**：只取当前章蒸馏三件套（章节结构 / 类比库 / 误区库）；目录骨架模式要在交付时说明「通用知识讲解」。
- **深度**：按 `state.md` 的「基础水平」：0 基础 = ELI5（5 岁小孩、小学生都能听懂）；有基础 = 常识一句带过，时间留给难点。口吻是老师上课。
- **在后台做**：先回一句「视频大概 X 分钟后发你」，不卡学习群；渲染、安装类重活不在群里做。
- **存放**：`~/.hermes/learning/[领域名]/progress-assets/解释视频/YYYY-MM-DD-主题/`，用 `--final` 出片后只留分镜和成片；用 `MEDIA:/绝对路径.mp4` 发飞书。
- **不替代考核**：看完问「哪一个画面你最不确定？」，再回到正常教学和小节考核。

## 三、卡住时的升级顺序

学生说「听不懂/不知道/没概念/太绕了」，或换类比后仍卡住：

1. 不重复原话，换一个完全不同的生活类比重讲（降速）。
2. 仍卡 → **视觉范本**：用 `show-me` 生成自包含单文件 HTML（零外部 CDN、适配深浅色、手机滑动顺畅；严禁技术黑话，用生活比喻并做好元素与概念一一对应）。保存到 `~/.hermes/learning/[领域名]/progress-assets/[书名]-第X章-[概念]-视觉范本-YYYY-MM-DD.html`，用 `MEDIA:/绝对路径.html` 发飞书。
3. 仍卡 → 问一句是否要**解释视频**（见第二节）；或直接走 `teaching-steps.md` 的**寓言教学法**。

## 四、ELI5 / 说人话

用户说「ELI5」「说人话」「讲简单点」「像给小孩讲」：本次讲解立即切到 0 基础讲法（先生活场景和类比、后术语、一次一个概念），并问是否把 `state.md` 的学习偏好改成「讲简单点」；用户同意才写入。
