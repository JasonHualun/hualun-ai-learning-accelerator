# 短回复与上下文丢失处理

> 由 SKILL.md 3.0.1 原文整段迁出（2026-09-28 压缩），规则原样保留；冲突处已按主 SKILL.md 统一。

### 学习群单字母/短回复防串上下文规则

在 AI 学习群或学习流程中，用户回复 `继续` / `1` / `2` / `A` / `B` / `C` / `对` / `好` 这类短消息时，默认只绑定到**最近一道学习题、课题选择、确认问题或当前学习步骤**。如果当前上下文刚经历 compression、摘要缺失、或看不出上一道题/选择项，必须先读 `~/.hermes/learning/**/state.md` 和最近 `section-notes/` 来恢复学习断点；仍不确定再问一句澄清。不要调用 `session_search` 去给短回复寻找旧的 GitHub、Skill 安装、配置方案等非学习上下文。学习进度恢复只读 `~/.hermes/learning/[领域]/state.md` 和最近 `section-notes/`，不能从残缺压缩摘要猜。

### 编号极简答案处理规则

当用户用 `1 小 2买方 3上升` 这种编号极简格式回答小节/章节考核时：
1. 默认绑定到当前最近一道考核题，不要要求用户改写完整句。
2. 按编号逐项解析并判定；全对时简短解释每项为什么对。
3. 小节题全对：立即更新 `state.md` + 轻量 `section-notes/`，再进入下一最小子项。
4. 章节综合题全对：立即执行章节收尾闭环：`state.md` 节点 ✅、1/7/30 天复习队列、Obsidian 章节笔记、`LLM Wiki/wiki/学习/AI学习/00-入口.md`；当前版本要求的章节互动复习卡（HTML及同名PNG）也要核对生成，不要漏。
5. 透明说明写入位置，但默认一句话即可；不要列一堆路径打断学习节奏。

详见 `references/numbered-compact-assessment.md`。

### 用户选择章节/目录序号时

当用户在书籍目录或学习骨架后回复「先学3」「学第3个」「从第2章开始」这类序号选择：
1. 将序号映射到目录中的对应章节/节点，简短确认章节名。
2. 若没有 state.md 或未记录基础水平，先问基础水平；不要直接开讲。
3. 若可开讲，只进入该章第一个最小子项，按费曼流程讲一个概念。
4. 禁止把整章内容整理成大纲式长文；禁止一次性列 4 个以上核心点；禁止一次性给 3 道以上测试题。学习课不是摘要报告，必须有来回。

### 极短回复与上下文丢失防护

当用户在学习群里只回复 `A/B/C/对/错/是/不是` 等极短答案时：
1. **默认解释为当前正在进行的学习题答案**，不得跨任务套到旧的 GitHub/Skill/配置方案选项里。
2. 如果上下文压缩、会话分裂、摘要缺失或当前题目不可见，不要用 `session_search` 主动给单字母找旧任务；先读取当前领域 `state.md` 和最近 `section-notes/`。
3. 若仍无法确定题目，必须问一句澄清："这个 A 是回答刚才哪道题？"，不要自行脑补。
4. 用户明确纠正"刚刚某小节已经上完"或"上过了/会了/继续啊"时，以用户最新纠正为准：不要重复讲、不要辩解；立即写 `section-notes/`、更新 `state.md`，然后从下一学习节点继续。章节级完成或收尾时再同步 Obsidian 学习首页。
5. 同一章的小节都已通过时，下一步是章节综合考核；不要编造不存在的下一小节。


### 上下文压缩/丢失恢复规则

当出现 context compression、会话摘要缺失、图片题/上一题不可见，或用户指出“上下文丢了”时：
1. 立即停止推进，不要根据残缺上下文回答。
2. 先读 `~/.hermes/learning/[领域]/state.md` 和最近的 `section-notes/` 确认进度。
3. 对单字母/短答，优先解释为当前学习题答案；若无法确定当前题，问用户确认，不得主动 `session_search` 旧任务来匹配。
4. 如果用户明确纠正“刚刚已经上完/已经通过”，立刻把 state.md、小节记录、Obsidian 学习首页同步到用户确认的进度，再继续下一步。
5. 报告写入位置，保持记忆透明。
