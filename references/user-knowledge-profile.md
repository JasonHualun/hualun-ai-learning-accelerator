# 用户学情档案系统

## 概述

跨学科的用户知识档案，记录用户的学习偏好、知识水平、阅读背景。每次开始新学科前读取，根据历史记录调整教学。

## 文件位置

```
~/.hermes/learning/user-profile.md
```

## 数据来源

### 1. 微信读书自动获取

配置 `WEREAD_API_KEY` 后，调用 `/shelf/sync` 接口获取：
- 书架总量（电子书 + 有声书/专辑 + 文章收藏）
- 已读完书籍列表
- 分类统计（按 category 字段聚合）
- 书单分类

**⚠️ 接口是 `/shelf/sync`，不是 `/shelf/list`**（后者会返回 -2003 错误）

### 2. 学习过程实时更新

根据用户反应词更新：
| 触发词 | 含义 | 教学调整 |
|--------|------|---------|
| "太简单/跳过/会了/上过了" | 水平比预估高 | 立即跳过，标记已掌握 |
| "太难/听不懂/等等/没理解" | 跟不上 | 换类比，降速，拆更细 |
| "为什么/凭什么/怎么来的" | 要求深层解释 | 给原理，不接受表面答案 |
| 沉默 / 只说"嗯" | 可能没懂 | 主动追问确认 |

## 档案格式

```markdown
# 用户学情档案
更新：YYYY-MM-DD

## 基本信息
- 书架总量：X 本
- 已读完：X 本
- 书单分类：[列表]

## 阅读偏好（按分类统计）
1. 分类A: X 本
2. 分类B: X 本
...

## 已读完书籍
1. 书名 - 作者 [分类]
...

## 知识领域分析
### 强项领域（读得多）
- 领域A：特点
### 待拓展领域
- 领域B：说明

## 学习偏好（实时更新）
- 节奏偏好：正常 / 偏快 / 偏慢
- 理解风格：逻辑推导型 / 类比直觉型 / 案例实操型
- 容易卡住的地方：[记录]

## 反应模式（实时更新）
| 触发词 | 含义 | 教学调整 |
|--------|------|---------|
```

## 初始化流程

在「固定开场白」的步骤一（静默扫描）前加：

```
#### 步骤零：读取用户学情档案
读取 ~/.hermes/learning/user-profile.md
├─ 有该学科记录 → 读取基础水平、掌握特点
├─ 无该学科记录但有微信读书数据 → 根据已读完书籍推测基础
└─ 无任何记录 → 标记"新学科"，按0基础处理
```

## 教学调整规则

1. **用户已读完相关书籍** → 有基础模式，快速过基础概念
2. **用户读过同领域大量书籍** → 可以用该领域概念类比新概念
3. **用户说"太简单/跳过"** → 立即记录到档案，后续不再重复
4. **用户说"太难/听不懂"** → 降速，换类比，记录到档案
5. **用户追问"为什么"** → 给深层原理，记录为"逻辑推导型"
