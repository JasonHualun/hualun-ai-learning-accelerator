# 微信读书 × AI学习法集成规则

## 核心定位

微信读书官方 Skill 在 AI 学习法中的主作用是：**给新书学习提供中文版书籍骨架**，不是替代费曼教学，也不是默认读取用户笔记/公开评论。

## 新书学习优先级

1. **优先微信读书**
   - 若已配置 `WEREAD_API_KEY`：直接用微信读书官方 Skill 搜书并取目录。
   - 若未配置：先询问用户是否有微信读书账号/会员。
   - 用户有账号/会员：引导打开 `https://weread.qq.com/r/weread-skills` 登录授权并配置 API Key。
   - 用户没有微信读书：回退本地 PDF/EPUB/TXT 流程。

2. **用微信读书做骨架，并蒸馏知识地图**
   - `/store/search`：确认目标书与 `bookId`。解析时遍历 `results[].books[].bookInfo`；不要只看顶层 `books`。
   - `/book/info`：拿中文书名、作者、简介、分类、评分等基础信息。
   - `/book/chapterinfo`：拿章节目录，作为中文学习骨架和 `state.md` 知识地图初稿；若章节条目带 `anchors[]`，优先将 anchors 作为章内小节/子项。
   - `/shelf/sync`：获取用户书架数据（电子书、有声书、书单），用于构建用户学情档案。
   - 拿到目录后必须先初始化/更新 `state.md` 知识地图：大节、章节、小节、当前节点、复习占位。
   - 进入教学前，按当前章节触发蒸馏：生成章节结构、类比库、误区库；不能只拿目录就直接长期裸讲。
   - **透明边界**：只拿到 `/book/chapterinfo` 时，必须说清"这是微信读书目录骨架 + 通用知识蒸馏"，不是逐页原文蒸馏；用户问"是蒸馏微信读书里的书吗"时要主动区分目录骨架、书籍元信息、正文原文三层。
   - **书名消歧**：`《经济学原理》`通常指曼昆 *Principles of Economics*；萨缪尔森/诺德豪斯的是 `《经济学》` (*Economics*)。如果当前学习材料是萨缪尔森/诺德豪斯，不要称为"经济学原理"。
   - **范围核对**：综合教材要说明总章数、微观/宏观分界和当前章节归属；例如萨缪尔森/诺德豪斯《经济学》第19版是微观+宏观综合教材，当前第1–18章偏微观、第19–31章偏宏观（以实时目录为准）。
   - 后续教学由 AI 学习法沿骨架推进：费曼教学、追问、考核、复习、Obsidian 沉淀。

3. **微信读书抓不到再回退本地**
   - 查本地教材目录：`~/Downloads/书籍/`。
   - 有文件则走原教材蒸馏流程。
   - 没有则要求用户上传/放置文件；非公版书不要从随机 PDF 站硬扒。

## 用户学情档案构建

开始新学科前，从微信读书获取用户阅读数据，构建学情档案：
- 调用 `/shelf/sync` 获取书架数据
- 筛选 `finishReading == 1` 的已读完书籍
- 按 `category` 统计阅读偏好
- 生成 `~/.hermes/learning/user-profile.md`

详细流程见 `references/user-profile-building.md`。

## 不默认调用的内容

不要默认抓取：
- 微信读书公开点评
- 热门划线
- 读者想法
- 评论区/热门内容

原因：token 成本高、噪声大、且对新书学习不必要。只有用户明确要求"看看评论/热门划线/大家怎么理解"时才调用。

## API 调用注意事项

- 书架接口是 `/shelf/sync`，不是 `/shelf/list`（2026-05-26 实测确认）
- 业务参数必须平铺到 body 顶层，不要包在 `params` 内
- 详细 API 模式记录见 `references/weread-api-patterns.md`

## 教学内容边界

- 微信读书目录提供**结构骨架**，不是章节正文全文。
- 如果只调用 `/book/chapterinfo`，必须对用户透明说明：这是"微信读书目录骨架 + 通用学科知识/教材常识蒸馏"，不是"逐页/逐段原文蒸馏"。不要说"已经蒸馏了微信读书里的书籍原文"。
- 大模型围绕骨架生成通俗讲解，使用作者 perspective 和费曼学习法；但章节结构/类比库/误区库文件中应标注来源层级（目录骨架、通用知识、本地原文）。
- 若用户要求严格逐页/逐章贴合原文，必须要求本地 PDF/EPUB/TXT 或可访问正文，再走真正的教材蒸馏流程。
- 用户询问"我学的是哪本/是不是《经济学原理》/微观还是宏观"时，先查 state.md + 微信读书 `/book/chapterinfo`，明确书名、作者、总章数、微观/宏观分界；不要凭记忆把《经济学》和《经济学原理》混用。

## 用户纠正的关键点

用户强调：他学的是"新书"，微信读书中通常没有个人划线；已在微信读书自己读过的书没必要再用 AI 学一遍。因此微信读书不应默认作为"个人划线诊断层"，而应作为"新书中文骨架来源"。
