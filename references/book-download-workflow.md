# 书籍下载工作流注意事项

## 下载前必须确认（2026-05-26 用户纠正）

**❌ 错误做法**：找到一个 PDF 就直接下载
**✅ 正确做法**：下载前先确认

1. **方向确认**：同一领域可能有多个方向（如"控制论"有维纳原著、钱学森工程控制论、现代控制理论）
2. **版本确认**：中文版 vs 英文版（用户偏好：默认中文，不用问）
3. **版权判断**：中文版教材通常是版权教材，网上没有免费 PDF

## 用户偏好

- **中文优先**：用户说"以后都优先中文 不用问"
- **不要自行下载**：下载前必须确认方向/版本，除非用户明确说"随便"或"都可以"

## 下载失败处理

当 archive.org / uberty.org 等海外源下载超时：
1. 用户有代理环境（端口按本机配置）
2. 使用 `--proxy http://<本机代理地址>:<端口>` 参数
3. 设置较长超时（180-300秒）

## 版权教材处理

中文版维纳《控制论》等版权教材：
- 网上没有免费 PDF
- 不能从随机 PDF 站、网盘镜像硬扒
- 正确做法：告知用户提供文件，放到 `~/Downloads/书籍/[学科名]/`
- 或使用微信读书骨架（目录结构 + 通用知识蒸馏）
