## 跨节点综合考核

每3个大节点完成后，做一次跨章综合题：优先用互动练习页（见 `interactive-practice.md`）；不方便打开网页时，退回聊天里2道综合情境题（不标注用哪个概念）

2道都通过 → 继续；有1道没过 → 标记薄弱节点，回到对应节点重学


## 章节综合考核（唯一的正式测试点）

学完本章所有子项后，出2-3道综合情境题（不标注用哪个概念），一道一道出，答完一道再出下一道。

**考核时说话要像在聊天**，比如：
- "来，道fireside chat，最后来几道综合题试试"
- "这几道没有标准答案，关键是你怎么用学过的道理想"

**⚠️ 教学节奏红线：绝对不能先问问题后讲概念。**

```
费曼第一步（困惑引入）→ 费曼第二步（类比建连接 → 精确定义）→ 用自己的话复述确认
  ↓
费曼第三步（例子深化 + 记忆绑定）→ 映射确认
  ↓
费曼第四步（追问）→ 发现漏洞 → 考核（最后）
```

**禁止**：
- ❌ 先问问题，学生答不上来才讲概念
- ❌ 一次性把多个概念全倒出来再问"懂了吗"
- ❌ 问完概念直接进下一个，中间不确认

考核方式：
- **迁移题** — 给一个没见过的情境，用概念分析
- **反例题** — 给一个看起来符合但实际不符合的情境，识别漏洞

两个同时通过 → 立即写入 state.md → 执行"章节末尾四件事" → 蒸馏下一章


## 章节末尾四件事（强制，综合考核通过后立即执行）

> **硬性边界（防跳章，实测教训 2026-08-18）**：四件事必须全部做完才能进下一章——尤其③错题感悟、④总结要**等用户确认/回应之后**才算收尾。四件事完成前**禁止**进入下一章教学；「收尾旧章」和「开讲新章」**不得混在同一轮回复**里。违反会打断上一章的收尾、腰斩总结流程。

### ① 本章概念清单

> "我们来整理一下，今天学的这些原理，你还记得哪些？"

逐个概念过：叫什么名字？核心定义是什么？

### ② 概念地图（可视化）

给出简版结构图，展示本章各概念之间的关系。格式：

```
第X章 [章节名]
├── 概念A：一句话
│   └── 关联/推论
├── 概念B：一句话
└── 概念C：一句话
```

### ③ 错题和感悟记录

问：
- "今天有没有哪个地方一开始听不懂，现在突然想通了？"
- "有没有哪个地方还是模糊的？"

记录进 state.md 的"误区记录"。

### ④ 章节总结（替代记忆宫殿，2026-08-18 改）

综合考核通过后，由助手直接输出本章总结，不再让学生走「记忆宫殿路线」。

**【极度通俗要求（强制）】**：这里的总结（特别是难点重讲和关系串讲）必须用**大妈和小学生都能听懂的大白话**来讲。用买菜、做饭、点外卖等最日常的生活场景打比方，坚决不拽词，绝对不堆砌专业术语。

总结分三层，缺一不可：

**第一层 · 重点清单**：把本章要记的概念逐个列清——概念名 + 一句话大白话定义，让学生一眼扫完全章重点。

**第二层 · 难点重讲**：本章比较难懂、容易绕的概念，从头梳理一遍（背景 → 类比 → 精确定义 → 边界），直到能用自己的话说清为止。

**第三层 · 关系串讲**：把整章概念的关系串成一条线——谁依赖谁、谁和谁是一组、谁管什么、本章主线闭环是什么。

**简洁要求（实测 2026-08-18）**：三层都要「少而准」——重点清单每概念一句话；难点只挑最绕的 1-2 个、每个 2-3 句讲清；关系用一句话或一条短链讲主线。禁止写成长段落小作文。

三层讲完，问一句「这几个难点里，还有没有哪个想我再展开的？」，确认后记录进 state.md 的「章节总结」段落：

```markdown
## 章节总结
### 第X章 [章节名]
- 重点：概念1 = 一句话；概念2 = 一句话；…
- 难点：概念A（重讲要点）
- 关系：A → B → C 的主线串讲
```

### 章节互动复习卡（每个大节/章节完成后强制生成，HTML 互动卡为主）

章节综合考核通过后，生成一份**「章节互动复习卡」**（自包含单文件 HTML，可配合无头浏览器导出同名 PNG 长图）。它同时承担复习卡和思维导图的作用：既能快速复习核心概念，也能清晰展示概念之间的关系，支持手机端滑动查看与考点一键复制。

**禁止**：
- ❌ 再额外生成零散的“知识卡”图片
- ❌ 充斥技术黑话或生硬学术腔（必须是小学生和买菜大妈听得懂的纯生活大白话）
- ❌ 依赖外部 CDN 导致离线/弱网加载失败

**命名规则与存储路径（按当前学习路由）**：
- 文件命名：`[书名]-第X章-复习图-YYYY-MM-DD.html`（及同名 `.png` 截图）
- 本地学习进度副本（路径完全不变）：
  ```text
  ~/.hermes/learning/[领域名]/progress-assets/[书名]-第X章-复习图-YYYY-MM-DD.html
  ```
- Obsidian 复习卡归档（已适配新 Wiki）：
  ```text
  LLM Wiki/wiki/学习/AI学习/复习卡/[书名]-第X章-复习图-YYYY-MM-DD.html
  ```

**触发时机**：章节综合考核通过，且完成「章节末尾四件事」后立即执行；不要等用户提醒。

**内容结构（四层架构，缺一不可）**：
1. **核心大白话速查字典**：本章每个核心概念配 1 句小学生比喻，绝不拽词，直击直觉。
2. **关系链滑动梯子**：清晰展示上下游依赖、先后循环链路，卡片式布局，在手机端顺畅滑动。
3. **避坑警示牌**：针对本章错题与常见误区，给出清晰的正误对比案例。
4. **考点一键复制**：每个重点模块配备一键复制按钮（`navigator.clipboard.writeText(...)`），方便随时拷走复习。

**视觉与交互规范**：
- 自包含单文件 HTML（内嵌样式与 JS，零外部网络依赖）；
- 手机端优先排版：字体清晰、间距舒适、支持深浅色模式自适应；
- 发送方式：飞书消息必须包含 `MEDIA:/绝对路径.html`（自动上传飞书云端，手机端点开即看，Mac 本地删除后手机依然可用）；
- 在章节学习笔记和 `LLM Wiki/wiki/学习/AI学习/00-入口.md` 中写入该复习卡链接。

**用户偏好**：每章只生成一份互动复习卡：一份发飞书，一份同文件副本保存到本地学习进度目录和 Obsidian。本地学习副本路径保持不变，Obsidian 路径按当前学习路由。
