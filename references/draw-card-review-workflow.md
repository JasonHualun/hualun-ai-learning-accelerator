# 抽卡复习工作流

适用触发：用户说「抽卡复习」「抽一张复习」「复习卡」「来一题复习」「抽一张卡复习」「来张复习卡」。

## 目标

像抽一张卡一样，快速给用户一题到期复习，不进入完整「开始学习」流程，也不长篇解释内部检索过程。

## 优先级

1. 先查 Memento 到期卡：
   ```bash
   python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py due
   ```
2. 如果 Memento 有 due cards：按 memento-flashcards skill 的一问一答流程出题，用户答完后必须给正确答案和简短反馈，再 rate。
3. 如果 Memento 没有 due cards：回退到 AI 学习状态文件：
   - 扫描 `~/.hermes/learning/**/state.md`
   - 读取每个 state.md 的「复习队列」
   - 选择 `到期日 <= 今天` 且状态为 `🔄` 的条目
   - 多个到期时优先最早到期；同日优先当前主线学习项目；也可跨主题随机一张，但一次只出一张
4. 如果没有任何到期复习：告诉用户目前没有到期卡，并可给一个「随机巩固题」选项，但不要擅自开始新课。

## 出题要求

- 只出一题，不堆题。
- 不说「选择题/判断题」这类考试腔。
- 遵守本 skill 的考核难度规则：不能词面送分；正确答案要藏在案例、解释、行为判断或边界条件里。
- 对用户明显掌握的基础概念，反馈一句话即可，不重复教学。

## 用户回答后

- 先判定答案并解释一句。
- 答对：简短说明为什么对，并把对应复习队列状态改为 `✅`。
- 答错/模糊：给正确答案和一句纠偏；不立刻标 `✅`，可当场补一题或标记薄弱。
- 写入后只透明说明一句：「已记录到学习进度。」不要列路径打断节奏。

## 注意

- 「抽卡复习」不是「继续学习新章节」：答完一张卡后不要自动开新课，除非用户明确说继续学习。
- Memento 是原子闪卡系统；AI 学习的 `state.md` 仍是课程进度、章节状态、误区和复习队列的事实源。抽卡复习可以结合两者，但不能用 Memento 替代 `state.md`。
- Memento 空不是失败；`state.md` 是课程复习的事实源。
- 日期必须取系统时间，不要猜。

## 会话样例

Memento 返回 0 张 due card，但 `RAG入门/state.md` 有到期的 1 天迁移复习项。正确做法是抽 RAG 复习题，用户答对后把该行状态改为 `✅`。
