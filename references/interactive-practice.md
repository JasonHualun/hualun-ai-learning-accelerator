# 互动练习页（2026-09-28 用户确认）

一个自包含 HTML 练习页：手机上点着做，每题当场判对错、给解释；做完点「复制答题码」，用户自己粘贴回对话。结果不自动回传（用户已否决 webhook 与飞书卡片方案）。

## 什么时候用

- 跨章综合考核（每 3 个大节点）：用练习页代替聊天里的 2 道综合题。
- 用户说「来个练习」「出份练习」「做套题」。
- 复习到期、用户选择做题复习时，可用练习页一次覆盖多个到期节点。

平时的小节考核仍在聊天里一道一道问，不生成练习页（生成耗 token，也打断节奏）。

## 怎么做

1. 以 `templates/practice-template.html` 为模板（第 1–4 章 Agent 设计模式样例），保留其结构、样式、答题码与复制逻辑，只换题目内容和 `PID`。
2. 题量 4–6 题、约 8 分钟；题型从模板里选：情境判断、点选排顺序（手机上点选，不用拖拽）、场景配对、判断对错、滑块/切换的可调小模型。
3. 出题只用已通过章节的内容；错误选项取自该课程 `{NN}-误区库.md` 和 state.md「误区记录」。遵守 `teaching-steps.md` 的考核规则：不词面送分、不弱智二选一、非互斥概念不出单选、图形题先给图。
4. 每题第一次作答计分并锁定；反馈写清为什么，尽量点名对应误区。
5. `PID` 格式：`<课程缩写>-<范围>-YYYY-MM-DD`，与文件名一致。保存到 `~/.hermes/learning/[领域名]/progress-assets/<PID>.html`，飞书用 `MEDIA:/绝对路径.html` 发送，附一句「做完点底部复制答题码，粘贴回来」。
6. 自包含单文件（零外部依赖）、手机优先、深浅色自适应，与章节互动复习卡同一规范。

## 收到答题码怎么处理

答题码形如：`练习 ADP-跨章1-4-2026-09-28 1:C✗ 2:序✓ 3:配3/4(提示链✗) 4:判✓✗✓ 5:B✓ 6分`

1. 按 `PID` 打开 `progress-assets/<PID>.html` 对回原题和正确答案；找不到文件就只按码里的对错记录，不猜题目内容。
2. 逐题判定：✓ 计通过；✗ 或部分对的，把对应概念写进 state.md「误区记录」（标日期和"练习"来源），并把该节点加入复习队列。
3. 跨章综合考核：全部 ✓ 或只错 1 题且当场补讲后答对 → 通过；错 2 题及以上 → 标记薄弱节点，回对应节点重学（同 `chapter-closing.md`）。
4. 回复只说结论和错题要点，一句话说明「已记录到学习进度」；错题各用 1–2 句重讲，再问要不要针对它补一道题。
